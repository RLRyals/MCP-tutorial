Scene Writing MCP - Essential Tools
Book Server (Core Structure)

get_chapter - To review the chapter plan before writing scenes
get_scene / list_scenes - To review existing scenes before adding new ones
create_scene - To create new scenes as they're written
update_scene - To update scenes with word counts and status changes

Character Server (Continuity Management)

check_character_knowledge - CRITICAL: To verify what characters know before writing
get_character_details - To ensure consistent character descriptions/traits
get_characters_in_chapter - To see who's supposed to appear in the chapter
add_character_knowledge_with_chapter - To track new knowledge acquired in scenes

Plot Server (Story Progression)

get_plot_threads - To check active threads relevant to the scene
create_information_reveal - To track when important information is revealed
add_reveal_evidence - To track evidence discovered during scenes

Relationship Server (Character Dynamics)

track_relationship_dynamics - To record relationship developments in scenes
get_relationship_arc - To check the current state of relationships

World Server (Setting Consistency)

get_locations - To ensure consistent location descriptions
get_world_elements - To verify magical/technological system details
track_location_usage - To record where scenes take place
track_element_usage - To record when magic/technology is used in scenes

Timeline Server (Chronological Tracking)

get_chapter_events - To see what events are happening chronologically
map_event_to_chapter - To record how events are presented in scenes
