Book Planning Server Tools
The book planning server focuses on the structure and elements specific to a single book, including its plot, chapter structure, and character arcs within that book.
1. Book Structure Tools

book-server:create_book - Create a new book entry
book-server:update_book - Update book details
book-server:get_book - Retrieve book information
book-server:list_books - View all books in the series

2. Plot Tools
